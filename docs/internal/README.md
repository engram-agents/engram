# Internal docs

Design notes, specs, research, team process and the release procedure for developing ENGRAM.
This folder is public: since v0.5.6 the whole development history ships in the public repository. It is not part of a user's install; it is written for the people and agents building ENGRAM.
A doc stays directly under `docs/` only if a shipped surface sends users to it; the allowlist is in `tests/test_docs_layout_guard.py`.
