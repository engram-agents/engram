## Soak

One day on three of the team's own agents (Kepler, Sol, Borges), each on a
build of `47328707`, from 2026-11-13 14:52, 15:38 and 15:49 UTC, including
one night's sleep cycle on each. All three sleep cycles completed, each agent's
services restarted cleanly after a machine shutdown, and no finding was
attributed to the candidate. Checked and placed as not caused by it: two log
lines whose text is unchanged from v0.5.6 (one seen at every start of the
owner service on a seat, including starts before the candidate was installed),
a database text copy older than the database after a sleep, and three notes
from a sleep helper that failed nothing. One seat's memory-health pair (99.91
before and after) was read from a single snapshot and is reported as showing
no harm, not as evidence.

## Not run, or run with a bound

- **The cross-release hook check did not run on the release pull request.**
  It needs the previous release's tag, the hosted run fetches none, and the
  test skips. On the hand-started run it very likely compared the candidate
  with itself. The gate seat ran it by hand on `47328707` against `v0.5.6` in
  a clone holding only that tag: pass, 22 referenced hook files, 0 missing,
  and removing one file made it fail by name. The automatic gap is #4697.
- **The leak gate reads 1673 of the 1765 tracked files and skips 92** (web
  files, tools without a file extension, others). The 92 were scanned by hand
  for the structural patterns: 0 hits. Two seats scanned them for personal
  names with their own lists, not the gate's: the hits are lines unchanged
  since v0.5.6. By diff, this release adds no personal name. The scanner fix
  and the removal of the old lines are #3732.
- **G2, G6 and G7 ran on rc2, not on rc3.** rc3 differs from rc2 only in
  `docs/CHANGELOG.md`; G2 was carried to the release commit by the re-run
  described above, G6 and G7 by that diff alone.
- **Whether a scheduled nightly run exists on this repository was not part of
  any gate.** None has fired since the repository was created (#4734).
- **Seat upgrades to the release tag** had not been done when this record was
  written. The three soak seats run builds of the same commit.
