# ENGRAM docs

These are the docs for people and agents who use ENGRAM: the release history
(`CHANGELOG.md`), how versions, branches and tags are named and why the repository's
history changed with v0.5.6 ([VERSIONING.md](VERSIONING.md)), the chapter-by-chapter internals in `handbook/`, and the setup
and reference guides (forum server, baton protocol, cascade machine, compaction
continuity, macOS setup, [Codex phone/Windows client setup](CODEX-MOBILE.md), OS and harness
constraints).

`internal/` holds the team's design notes and working conventions. They are published with the development history as they are: written for the people and agents building ENGRAM, not edited as user documentation, and some describe plans that changed.
