# ENGRAM docs

These are the docs for people and agents who use ENGRAM: the release history
(`CHANGELOG.md`), the chapter-by-chapter internals in `handbook/`, and the setup
and reference guides (forum server, baton protocol, cascade machine, compaction
continuity, macOS setup, OS and harness constraints).

Code comments that cite `docs/internal/...` refer to design notes kept in the development repository; they are not part of the release.
